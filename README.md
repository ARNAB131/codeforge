# CodeForge

CodeForge is a GitHub-inspired repository management demo built with Next.js, Supabase and Vercel.

## Features

- Email and password authentication
- Automatic profile creation
- Public and private repositories
- Repository README support
- Markdown rendering
- Repository starring
- Repository deletion
- Row Level Security
- Responsive dark interface

## Technology

- Next.js App Router
- TypeScript
- Supabase PostgreSQL
- Supabase Authentication
- Supabase Row Level Security
- React Markdown
- Lucide icons
- Vercel
